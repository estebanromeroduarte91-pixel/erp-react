# Campaña Instagram Pixit

Colección inicial para presentar Pixit a dueños de servicios técnicos.

## Entregables

- `exports/01-...` a `exports/09-...`: publicaciones para feed, 1080 × 1350 px.
- `exports/reel-...`: portadas verticales para Reels, 1080 × 1920 px.
- `captions.md`: textos y orden sugerido de publicación.
- `campaign.html`: fuente editable de todas las piezas.

## Volver a exportar

Desde la raíz del proyecto:

```bash
node marketing/instagram/render.mjs
```

Las capturas incluidas en esta entrega fueron sanitizadas: no contienen datos
personales legibles de clientes. Antes de reemplazarlas por una captura nueva
de producción, revisar siempre nombres, teléfonos, correos, RUT y cifras internas.
