# Pixit · Campaña Instagram 02

Diez piezas de feed en formato vertical 1080 × 1350 px, diseñadas a partir de la línea visual entregada: blanco, tipografía de alto peso, azul eléctrico, degradado violeta, mucho espacio y mockups de producto.

## Entregables

- `exports/`: imágenes PNG listas para publicar.
- `captions.md`: texto sugerido para cada publicación.
- `campaign.html`: fuente editable de las diez gráficas.
- `render.mjs`: exportador de las piezas.

## Exportar nuevamente

Desde la raíz del proyecto:

```bash
node marketing/instagram/Pixit-Instagram-Campana-02/render.mjs
```
